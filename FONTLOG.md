# FONTLOG for jinjer sans

## 1.0.0 — 2026-08-23

- Created a horizontal Japanese/Latin UI family from Inter 4.1 and Noto Sans JP.
- Fixed the public `wght` axis at 100–900 with a default of 400.
- Mapped public weights to visually balanced Inter/Noto source locations.
- Applied Gen Interface JP-derived 92.5% Japanese scale, baseline and proportional spacing policy.
- Added jinjer-specific outlines for 26 approved characters and their related OpenType alternates.
- Added static Thin, Regular, Bold and Black instances.
- Restored Inter mark-filtering sets and stable Regular layout data so OTS accepts the font and Latin kerning remains active.
- Added a non-overlapping jinjer UI core slice and Unicode-range Web delivery: static 400/700 by default, variable 100–900 for controlled trials.
- Added installation documentation, transfer-budget enforcement and automated QA.
