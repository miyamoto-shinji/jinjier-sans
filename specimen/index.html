05 / Web integration

01CDNへファイルを配置

dist/web/の中身を丸ごとアップロードします。CSSからWOFF2を相対パスで参照するため、フォルダ構成は変更しません。

https://cdn.example.com/fonts/jinjer-sans/1.0.0/
├── jinjer-sans.css              # 本番用：400 / 700
├── jinjer-sans-variable.css     # 検証用：100–900
├── jinjer-sans-full.css         # 分割なし・診断用
├── jinjerSans-VF.woff2
├── tokens.css
├── manifest.json
├── w/
│   ├── 400/                     # Regularの分割WOFF2
│   ├── 700/                     # Boldの分割WOFF2
│   └── vf/                      # 可変版の分割WOFF2
└── nam/                         # 各分割ファイルのUnicode一覧
02本番用CSSを読み込む

通常のWebサイトとプロダクトでは、転送量を抑えた400／700のjinjer-sans.cssを使います。

<link
  rel="stylesheet"
  href="https://cdn.example.com/fonts/jinjer-sans/1.0.0/jinjer-sans.css"
>

font-display: swapとUnicode-rangeは設定済みです。画面で使われた文字に必要なWOFF2だけを取得します。

03アプリでフォントを指定

デザイントークンを定義し、本文だけでなくボタンや入力欄にも同じフォントを指定します。本番CSSのウェイトは400と700です。

:root {
  --font-family-sans:
    "jinjer sans", Inter, "Noto Sans JP", sans-serif;
}

html,
button,
input,
select,
textarea {
  font-family: var(--font-family-sans);
}

body { font-weight: 400; }
strong,
.heading { font-weight: 700; }
04可変版を検証で試す

Storybook、比較見本、機能フラグ付き検証では可変版を使います。本番用CSSと可変版CSSは同じページで同時に読み込みません。

<link
  rel="stylesheet"
  href="https://cdn.example.com/fonts/jinjer-sans/1.0.0/jinjer-sans-variable.css"
>

<style>
  .variable-heading {
    font-family: "jinjer sans", sans-serif;
    font-weight: 550;
  }
</style>
